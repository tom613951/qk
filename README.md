# DataVision 全球数据可视化大屏系统

DataVision 是一套基于 **HTML5 + CSS3 + JavaScript (Vanilla)** 开发的炫酷、复杂的全球大数据可视化大屏系统。系统采用深色科技风设计，集成了大量动效、多维图表以及全自动的屏幕自适应系统，支持离线完美渲染，非常适合投影展示、数据监控中心或多端大屏显示。

🌐 **线上部署演示链接**：[https://qk-one.vercel.app](https://qk-one.vercel.app)

---

## 🖥️ 7 大主题大屏展示

本系统采用一主六辅的架构，共包含 7 个高度关联的大屏监控中心，支持在页面顶部导航栏或特定图表区域进行 3D 渐变转场下钻：

### 1. 🌍 全球数据指挥中心 (`index.html`) —— 主控中心
系统的核心入口，拥有全球数据拓扑飞线图（Canvas 粒子星空背景）、全球在线用户翻牌器、24H全球事件趋势、系统运行状态（CPU/内存/网络）、全球流量吞吐量与热门区域排行榜。

### 2. 🏙️ 智慧城市监控中心 (`smart-city.html`)
展示城市人口流动热力点位、交通拥堵指数雷达图、24H公共设施（水电网络）使用率、空气质量 AQI 精细化指标、能源消耗趋势以及城市今日安全事件玫瑰图。

### 3. 🛡️ 网络安全防御中心 (`cyber-security.html`)
实时监控全球网络威胁态势、DDoS 与 SQL 注入攻击路径、威胁等级分布漏斗、防火墙负载状态指标组、流量异常 AI 监测与漏洞修补进度看板。

### 4. 🏭 工业物联网监控中心 (`industrial-iot.html`)
包含设备在线率球形图、三条主产线产能利用率分析、设备故障日志列表、工厂设备点位热力图、7日能耗以及生产品质甘特图。

### 5. 💹 金融交易监控中心 (`financial.html`)
模拟 Bloomberg 终端，包含全球资金流向飞线图、实时行情滚动面板、多维资产配置旭日图、股票 K 线图与成交量均线、市场风控指标与交易热度排行。

### 6. 🌿 环境监测中心 (`environmental.html`)
展示中国地图及各省市 AQI 渲染层、全国监测站点 PM2.5 分布、四大流域水质指标变化、分类碳排放趋势以及生态指标雷达图。

### 7. 🏥 医疗健康大数据中心 (`healthcare.html`)
展示全国医院及 ICU 床位占用率水球图、十大科室疾病分布、药品消耗与库存对比、全国急救资源热力图、传染病多曲线趋势与医疗设备状态矩阵。

## 🌟 核心技术亮点与特效

*   **完全自适应 (Auto-Scale)**：基于 `transform: translate(-50%, -50%) scale(scale)` 的算法，自动等比适配任何分辨率的显示设备（以 1920x1080 为基准），在 100% 浏览器下完美居中贴合，杜绝切边和滚动条。
*   **星空粒子 Canvas**：内置全局 Canvas 粒子碰撞连线星空背景，增强界面的科技感和动感。
*   **3D 立体转场**：页面切换时配有全屏毛玻璃与比例微缩淡出过渡，提供无缝的原生 App 式体验。
*   **数据本地化 (100% 离线运行)**：地图 JSON 数据（世界与中国）已完成本地化下载，不依赖任何外部 CDN 地图库，在无网络的环境中依然可以秒开渲染。
*   **实时数据模拟**：各个图表及滚动列表与数据翻牌器均绑定了定时更新机制，实时变化且伴随流畅的数据动画。

## 🛠️ 快速上手与本地启动

由于本系统为纯静态 HTML5 应用，无需任何构建步骤，直接双击 HTML 文件或使用本地静态服务器启动即可：

1.  **使用 Python 一秒启动本地服务**：
    ```bash
    python -m http.server 8080
    ```
2.  **访问本地链接**：
    在浏览器中输入 `http://localhost:8080` 即可开始体验。
